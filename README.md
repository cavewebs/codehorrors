# CodeShame

A small React app for posting and browsing examples of bad code. Filter by category and tags, vote, and write up why a snippet is a problem.

The submissions on the home page are fictional samples. Nothing is saved to a server.

## Stack

- React 19
- TypeScript
- Vite 7
- Tailwind CSS

## Run it

You need Node.js 18 or newer.

```bash
cp .env.example .env
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

```bash
npm run build
npm run preview
```
